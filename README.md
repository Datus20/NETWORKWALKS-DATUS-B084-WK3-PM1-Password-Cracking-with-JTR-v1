# NETWORKWALKS-DATUS-B084-WK3-PM1-Password-Cracking-with-JTR-v1
Password Cracking with John The Ripper Tool (JRT)
By Using tool called JRT which contain the back-end which doesn't contain a CLI (_Command Line Interface_)  which us known as john, and the front-end GUI(_Graphical User Interface_) which is known as Johnny

       

📌 Project Overview
This project focuses on testing the password integrity  of the locked PDF file with a password and determine the password of the locked PDF usintg the tools known as john The Ripper JRT 

🎯 Objectives
The main objectives of this project are to:

To Download the JRT Tool
Install the JRT Tools
Obtaining The Has of the PDF file using Online Hashtool
Using the hash on JRT to test integrity of the Password 
Testing the obtained Password from the Tool

🛡️ Purpose of the Project
The Purpose of this project is to do Scan the Network inorder to identify the Host in the network as well, Service ports in the network as wll as the Network Topology by using Kali tool Nmap or Zenmap (GUI of Nmap) which is already pre installed in kali linux.

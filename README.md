This project focuses on testing the password integrity  of the locked PDF file with a password and determine the password of the locked PDF usintg the tools known as john The Ripper JRT 

## 🎯 Objectives

The main objectives of this project are to:

- To download & Install the **JRT Tools**.
- Obtaining The Has of the PDF file using Online **Hashtool**.
- Using the hash on **JRT** to test integrity of the Password.
- Testing the obtained Password from the Tool.
